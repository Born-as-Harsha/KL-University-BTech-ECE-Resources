# 📡 Digital Communication.

This repository contains organized study materials, lab resources, and reference content for the **Digital Communication** course offered in the **B.Tech ECE program at KL University**.

---

## 📂 Repository Structure

```
DIGITAL COMMUNICATION/
│
├── MID/            → Mid exam preparation materials
├── Octavelab/      → Octave/Matlab lab programs and simulations
├── PPTS/           → Lecture presentations (slides)
└── README.md       → Project overview and details
```

---

## 📘 Contents Overview

### 🔹 MID

* Important questions
* Short notes
* Previous exam preparation materials

### 🔹 Octavelab

* Digital communication simulations
* Modulation techniques (ASK, FSK, PSK, etc.)
* Signal processing codes using Octave/Matlab

### 🔹 PPTS

* Lecture slides provided during classes
* Concept explanations for:

  * Sampling
  * Quantization
  * Modulation techniques
  * Noise analysis
  * Channel capacity

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/DIGITAL-COMMUNICATION.git
   ```

2. Navigate to folders based on your need:

   * Exam prep → `MID`
   * Lab work → `Octavelab`
   * Theory → `PPTS`

3. Run Octave files:

   ```bash
   octave filename.m
   ```
