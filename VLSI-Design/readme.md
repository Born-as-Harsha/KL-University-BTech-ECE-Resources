
# ⚙️ VLSI Design & LTspice Simulations – ECE

This repository contains study materials, simulations, lecture notes, and resources for **VLSI Design**, including **LTspice simulations**, for the **B.Tech ECE program at KL University**.

---

## 📂 Repository Structure

```id="vlsi-structure"
VLSI DESIGN/
│
├── Homeassignmet-Alms/     → Home assignments (ALMS submissions)
├── LTspice-simulations/    → LTspice circuit simulations
├── Midresource/            → Mid exam preparation materials
├── PPT/                    → Lecture presentations
├── Texkbooks/              → Reference textbooks
└── readme.md               → Repository overview
```

1. Clone the repository:

   ```bash

   ```

2. Explore folders:

   * Assignments → `Homeassignmet-Alms`
   * Simulations → `LTspice-simulations`
   * Theory → `PPT`
   * Exam prep → `Midresource`

3. Open simulation files using **LTspice**.
