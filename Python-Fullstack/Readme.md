## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/PFSD.git
   ```

2. Navigate to a project:

   ```bash
   cd DjangoProject
   ```

3. Run Django project:

   ```bash
   python manage.py runserver
   ```

4. Run Flask project:

   ```bash
   python app.py
   ```
